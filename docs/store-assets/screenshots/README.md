# Store Screenshots

Chrome Web Store requires **1280×800 PNG** (or 640×400) screenshots. Provide 3–5.

## How to capture
1. Load the unpacked extension from `extension/dist/`.
2. Open Chrome at exactly **1280×800** (DevTools → device toolbar → Responsive → 1280×800, DPR 1).
3. Capture each view below with the OS screenshot tool, and save under this folder as `01-*.png`, `02-*.png`, etc.

## Required shots
1. `01-sidepanel.png` — Side Panel, Memories view with a few projects pinned.
2. `02-conversation.png` — Conversation viewer, "Continue in" menu open.
3. `03-search.png` — ⌘K universal search with grouped results.
4. `04-knowledge.png` — Knowledge section with entity chips.
5. `05-ai-center.png` — Ask Memlace with an answer streaming.

Keep the theme in **light mode** for the store; add matching dark-mode variants as bonus.
