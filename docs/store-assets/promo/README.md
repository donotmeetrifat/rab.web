# Promo Tiles

Drop finished PNGs in this folder. Sizes required by the Chrome Web Store:

| File | Size |
|---|---|
| `small-440x280.png` | 440 × 280 |
| `large-920x680.png` | 920 × 680 (optional) |
| `marquee-1400x560.png` | 1400 × 560 (optional, needed for featured placement) |

Use the Memlace blue (`#2563EB`) and the "M" wordmark on a `#FAFAF9` background for consistency with the extension's design system.
