# Support

## Self-serve
- Open the extension → **Help** for shortcuts, FAQ, and troubleshooting.
- Open **Diagnostics** to see counts, storage usage, and the version report you can copy into any bug report.
- Use **Diagnostics → Download full backup** before trying any troubleshooting step that touches data.

## Common issues

**"Save to Memlace" button doesn't appear on a chat page.**
The site may have shipped a UI change. Reload the page. If it still fails, the floating fallback button appears in the bottom-right after ~2 seconds.

**Conversation didn't auto-save.**
Auto-save is off by default. Enable it in Settings, or use the pill button in the composer toolbar.

**Search returns nothing after import.**
Open the target conversation once — the in-memory index rebuilds lazily.
